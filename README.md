# Vencimientos

Alimentos, medicinas, productos, suscripciones, pagos y garantías, con avisos antes de que venzan.

## Publicarla

1. Crea un repositorio público llamado `vencimientos` y sube todos estos archivos a la raíz.
2. En **Settings → Pages** elige la rama `main` y la carpeta `/ (root)`.
3. Abre en Chrome `https://tu-usuario.github.io/vencimientos/` e instálala.

## Actualizar la app

Si cambias algún archivo, abre `sw.js` y sube el número de `VERSION` (por ejemplo, de `vence-v1` a `vence-v2`).
